## 📌 Sobre o Projeto

O **Capuava Team** é o hub digital oficial da equipe brasileira independente de **Tom Clancy's Rainbow Six Siege (R6S)** baseada em Santo André, São Paulo. 

O projeto conta com duas experiências web:
1. **Versão 1 (Clássica):** Layout clean, minimalista e direto ao ponto com informações essenciais do time.
2. **Versão 2 (Cyber Tactical HUD):** Interface imersiva estilo esports cyberpunk, repleta de efeitos visuais, áudio tático procedimental (Web Audio API), radar canvas interativo, dossiês confidenciais e simulador de patente.

## 🚀 Recursos & Efeitos da Versão 2 (HUD)

- 🔊 **Sintetizador de Áudio Tático (Web Audio API):** Efeitos sonoros procedurais gerados pelo navegador (sem arquivos MP3 pesados). Atalho de teclado `M` para silenciar/ativar.
- 🌌 **Radar & Partículas em Canvas:** Fundo com constelação interativa de partículas e varredura de radar em tempo real.
- 🎯 **Mira Cibernética (Custom Cursor):** Cursor em formato de retículo tático com exibição de coordenadas `X/Y` e mira travada em botões e cards.
- 🃏 **3D Tilt & Holographic Sheen:** Efeito de inclinação tridimensional nos cards com reflexo de luz dinâmico acompanhando o ponteiro do mouse.
- 📂 **Dossiê Tático Confidencial (Modal):** Painel detalhado para cada operador com armamento, gadgets, falas de assinatura e barras de atributos.
- 🧮 **Simulador Tático de Vitórias:** Ferramenta interativa com slider para calcular o MMR projetado e probabilidade de promoção de patente.
- ⚖️ **Comparador 1v1 Interno:** Confronto estatístico direto entre dois operadores da line-up.
- ⏱️ **Cronômetro Regressivo ao Vivo:** Contagem regressiva em tempo real para a próxima ranked MD3 contra o time rival *Os Pratas*.
- 🎨 **Seletor de Temas HUD:** 4 frequências de cores táticas alternáveis instantaneamente (*Cyan*, *Molten Orange*, *Bio Hazard Green* e *Void Purple*).

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico:** Estruturação acessível e otimizada para SEO.
* **CSS3 Moderno:** Flexbox, CSS Grid, Custom Properties (variáveis), Animações 60fps com aceleração por hardware e Glassmorphism.
* **JavaScript Puro (Vanilla ES6+):**
  * Web Audio API (Síntese sonora procedimental)
  * HTML5 Canvas API (Partículas e radar)
  * IntersectionObserver (Contadores numéricos com easing)
* **GitHub Pages:** Deploy e hospedagem contínua gratuita.

## 💻 Como Rodar o Projeto Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Zaratini26/Capuava-Team.git
   cd Capuava-Team
   ```

2. **Abra no seu navegador favorito:**
   * Para a versão clássica: Abra o arquivo `index.html`
   * Para a versão nova com efeitos: Abra o arquivo `v2/index.html`

> 💡 *Dica:* Se você utiliza o VS Code, pode abrir com a extensão **Live Server** para recarregamento automático.
